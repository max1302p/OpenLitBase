# Eigene Zitierstile

Hier abgelegte `.csl`-Dateien erscheinen nach einem Neuladen der Seite in der Stil-Auswahl
(Einstellungen und Projekte). Der Dateiname ohne `.csl` ist die Stil-ID.

- Stile finden: <https://www.zotero.org/styles> oder <https://github.com/citation-style-language/styles>
- Nur **unabhängige** Stile funktionieren (keine „dependent“ Styles, die auf einen Parent verweisen).
- Braucht ein Stil eine Sprache, die nicht mitgeliefert wird, die passende `locales-xx-XX.xml` aus
  <https://github.com/citation-style-language/locales> in `custom-styles/locales/` legen.

Mitgeliefert (in `packages/citation/styles`): IEEE (Deutsch), IEEE, APA 7, DIN 1505-2,
Harvard (Cite Them Right), Chicago (author-date).
